Hello! My name is Kanayo Egwuekwe-Maxey. I'm a current CS student at Morehouse College from Chicago. This is the landing page for my personal project. The purpose of this project is to learn and practice front-end developement using HTML, CSS, and JS to talk about one of my favorite topics, Japanese Culture. I've grown up consuming Japanese culture and learned to love their music, cartoons, food, and culture. As such, I wanted to use this website to display my appreciation for their culture and accurately portray my favorite parts of their culture in creative ways. Throughout the website, you will see different applications of API calls, CSS animations, and CSS styling. This is an active project so, things are not guaranteed to look or function the same way they did in the past. This means, if there are any features or parts of the website that are appealing or unfavorable, please, contact me! The more feedback, the better. Thank you!
